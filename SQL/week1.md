## 01.

```
개념 이름: SQL
개념 설명: SQL(Structured Query Language)은 데이터베이스에 저장된 데이터를 조회하고 필요한 형태로 가공하기 위해 사용하는 언어이다.
활용 상황: 쇼핑몰의 고객 데이터에서 특정 상품을 구매한 고객을 찾거나,
월별 매출을 계산하는 등 많은 데이터 중 필요한 정보만 추출하고 분석할 때 활용할 수 있다.
```

## 02.

```
개념 이름: 데이터베이스와 테이블
개념 설명: 데이터베이스(Database)는 여러 데이터를 체계적으로 저장하고 관리하는 공간이다.
데이터베이스 안에는 데이터를 표 형태로 저장하는 테이블(Table)이 존재한다.
활용 상황: 기업에서는 고객 정보, 상품 정보, 주문 정보 등을 각각의 테이블로 저장하여 관리할 수 있다.
필요한 경우 SQL을 사용해 여러 테이블에서 원하는 데이터를 조회하고 분석할 수 있다.
```

## (선택) 03.

```
개념 이름: BigQuery와 데이터 활용 과정
개념 설명: BigQuery는 Google Cloud에서 제공하는 클라우드 기반 데이터 분석 서비스이다.
많은 양의 데이터를 저장하고 SQL을 이용하여 데이터를 빠르게 조회하고 분석할 수 있다.
활용 상황:  기업에서 고객의 구매 데이터를 BigQuery에 저장한 뒤 SQL을 이용하여
인기 상품, 고객별 구매 패턴, 월별 매출 등을 분석할 수 있다.
분석한 결과는 마케팅 전략이나 상품 기획과 같은 의사결정에 활용할 수 있다.
```

# 3️⃣ 확인 문제

## 🧩 문제 1

포켓몬 게임이나 이커머스 산업과 같이 다양한 산업에서는 각기 다른 데이터가 존재합니다. 다음 중 하나의 산업을 선택하고, 해당 산업에서 수집하고 활용될 수 있는 데이터 항목, 즉 컬럼 5가지를 자유롭게 상상하여 나열해주세요.

예시 산업:
- 온라인 음식 배달
- 스마트 헬스 케어
- 중고 거래 앱
- 교육 플랫폼

풀이 과정:

```
- 선택한 산업: 온라인 음식 배달
- 떠올린 컬럼 5가지:
  1. 주문 ID
  2. 고객 ID
  3. 음식 카테고리
  4. 주문 금액
  5. 주문 시간
- 해당 컬럼이 필요하다고 생각한 이유:
1. 주문 ID
각각의 주문을 구분하기 위해 필요하다.
주문마다 고유한 번호를 부여하면 특정 주문을 쉽게 조회할 수 있다.

2. 고객 ID
어떤 고객이 주문했는지를 확인하기 위해 필요하다.
이를 활용하면 고객별 주문 횟수나 구매 패턴을 분석할 수 있다.

3. 음식 카테고리
한식, 중식, 일식, 치킨 등 고객이 어떤 종류의 음식을 주문했는지 확인하기 위해 필요하다.
이를 통해 인기 있는 음식 종류를 분석할 수 있다.

4. 주문 금액
고객이 한 번의 주문에서 얼마를 사용했는지 확인하기 위해 필요하다.
이를 활용하면 전체 매출이나 고객별 평균 주문 금액 등을 계산할 수 있다.

5. 주문 시간
고객이 언제 주문했는지 확인하기 위해 필요하다.
이를 활용하면 점심이나 저녁 등 주문이 많이 발생하는 시간대를 분석할 수 있다.
```

## 🧩 문제 2

이번 강의를 통해 SQL이 왜 필요하다고 느끼는지, SQL을 통해 본인이 어떤 것을 해내고 싶은지를 자유롭게 작성해주세요.

풀이 과정:

```
- SQL이 필요하다고 느낀 이유: SQL을 사용하면 많은 데이터 중에서도 내가 원하는 조건의 데이터만 빠르게 조회할 수 있기 때문에 데이터를 분석하는 데 필요한 기본적인 도구라고 생각했다.
- SQL로 해보고 싶은 일: 실제 기업이나 금융 데이터를 활용하여 필요한 정보를 직접 추출하고 분석해보고 싶다. 예를 들어 고객의 구매 행동이나 기업의 매출 데이터를 분석하여 특정한 패턴이나 의미 있는 특징을 찾아보고 싶다.
- 앞으로 SQL을 공부할 때 기대되는 점: 지금은 SELECT, FROM과 같은 기본적인 문법을 배우고 있지만,
앞으로 조건을 설정하거나 여러 데이터를 연결하고 집계하는 방법까지 배우면
실제 데이터에서 원하는 정보를 스스로 추출할 수 있을 것 같아 기대된다.
```

# 4️⃣ 이번 주 회고

```
1. SQL을 처음 써보면서 가장 낯설었던 점: 정확한 테이블 이름을 입력해야 한다는 점이 낯설었다.
특히 BigQuery에서 테이블 이름을 잘못 입력하면 데이터를 불러올 수 없다는 점을 직접 경험하면서
데이터의 위치와 이름을 정확하게 확인하는 것이 중요하다는 것을 알게 되었다.
2. 다음 주에 더 익숙해지고 싶은 부분: SELECT와 FROM뿐만 아니라 데이터를 정리하고 집계하는 방법에 더 익숙해지고 싶다.
3. 과제 진행 중 막혔던 부분이 있다면: BigQuery에서 SQL을 실행할 때 테이블 이름을 잘못 입력하여
'Table was not found' 오류가 발생했다.
처음에는 오류의 원인을 알기 어려웠지만,
왼쪽의 데이터 구조에서 실제 테이블 이름을 확인한 후 수정하여 해결할 수 있었다.
이를 통해 SQL에서는 테이블명과 컬럼명을 정확하게 입력하는 것이 중요하다는 것을 알게 되었다.
```
