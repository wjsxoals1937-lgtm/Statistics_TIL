# 1️⃣ 개념 정리 

## 01. 통계적으로 추론하기

<!-- 새롭게 배운 내용을 자유롭게 정리해주세요.-->
통계적 추론은 전체 데이터를 모두 조사하기 어려울 때, 표본 데이터를 이용해 모집단의 특성을 추정하거나 가설이 타당한지 검증하는 방법이다.
- 모수검정: 표본 데이터를 바탕으로 모집단의 평균이나 분산과 같은 모수를 추정하고 검정하는 방법이다.
- 표준점수(Z-score): 데이터가 평균으로부터 표준편차의 몇 배만큼 떨어져 있는지 나타낸다. 서로 다른 데이터의 상대적인 위치를 비교할 때 활용할 수 있다.
- 중심극한정리: 모집단의 분포가 정규분포가 아니더라도, 표본 크기가 충분히 크면 표본평균의 분포가 정규분포에 가까워지는 경향이 있다는 원리이다.
- 표준오차: 표본평균이 표본을 추출할 때마다 얼마나 달라질 수 있는지를 나타내는 값이다. 표본 크기가 커지면 일반적으로 표준오차는 작아진다.
- 신뢰구간: 표본 데이터를 이용해 모집단의 모수가 존재할 것으로 추정되는 구간을 계산하는 방법이다.
- 가설검정: 영가설과 대립가설을 설정하고, 표본 데이터가 가설을 뒷받침하는지 판단하는 방법이다. 일반적으로 p-값이 0.05보다 작으면 유의수준 5%에서 영가설을 기각한다.
  
## 02. 머신러닝으로 예측하기

<!-- 새롭게 배운 내용을 자유롭게 정리해주세요.-->
머신러닝은 데이터에서 패턴을 학습하여 새로운 데이터의 결과를 예측하는 방법이다. 통계적 추론이 모집단의 특성을 추정하거나 가설을 검증하는 데 초점을 둔다면, 머신러닝은 학습한 패턴을 활용해 새로운 데이터의 값을 예측하는 데 활용할 수 있다.
- 지도 학습: 입력 데이터와 정답에 해당하는 타깃을 함께 사용하여 모델을 학습시키는 방법이다.
- 비지도 학습: 정답인 타깃 없이 데이터 자체의 패턴이나 구조를 찾는 방법이다.
- 훈련 세트와 테스트 세트: 훈련 세트는 모델을 학습시키는 데 사용하고, 테스트 세트는 학습에 사용하지 않은 데이터에 대한 예측 성능을 평가하는 데 사용한다. 이를 통해 모델이 새로운 데이터에도 잘 적용되는지 확인할 수 있다.
- 선형 회귀(Linear Regression): 입력과 타깃 사이의 관계를 직선 형태의 함수로 학습하여 연속적인 값을 예측하는 알고리즘이다. 학습 과정에서 기울기와 절편을 구한다.
- 결정계수(\(R^2\)): 회귀 모델이 타깃의 변동을 얼마나 설명하는지 나타내는 지표이다. 일반적으로 1에 가까울수록 해당 데이터에서 설명력이 높다.
- 로지스틱 회귀(Logistic Regression): 이름에는 회귀가 들어가지만, 주로 데이터를 특정 범주로 분류하는 데 사용하는 알고리즘이다.
- 정확도(Accuracy): 분류 모델이 전체 예측 중 실제 정답을 맞힌 비율이다.
- 기준 모델(Baseline Model): 복잡한 머신러닝 모델과 성능을 비교하기 위한 단순한 모델이다. 예를 들어 DummyClassifier는 입력 데이터의 특성을 활용하는 대신 단순한 규칙으로 클래스를 예측한다.

## 문제 1.

> **🧚Q. 어떤 표본의 크기가 충분히 크고(n ≥ 30), 모집단 분산을 알 수 없을 때 모평균에 대한 신뢰구간을 구하려고 한다.
이때 다음 설명 중 가장 적절한 것은 무엇인가?**

```
1️⃣ 표본의 크기가 충분히 크므로 중심극한정리에 의해 표본평균의 분포는 근사적으로 정규분포를 따른다.  
2️⃣ 모집단 분산을 모르므로 신뢰구간을 구할 수 없다.  
3️⃣ 표본이 30개 이상이면 항상 모집단도 정규분포를 따른다.  
4️⃣ 중심극한정리는 모집단이 정규분포일 때만 적용된다.
```

```
여기에 정답을 적어주세요!
정답: 1️⃣
표본의 크기가 충분히 크면 중심극한정리에 의해 표본평균의 분포는 근사적으로 정규분포를 따른다. 모집단 분산을 모르더라도 표본표준편차를 이용해 모평균의 신뢰구간을 구할 수 있다. 표본 크기가 30 이상이라고 해서 모집단 자체가 정규분포를 따른다는 뜻은 아니다.
```

## 문제 2.

> **🧚Q. 다음 중 순열검정(permutation test)에 대한 설명으로 가장 옳은 것은 무엇인가?**

```
1️⃣ 모집단이 정규분포를 따른다는 가정을 반드시 해야 한다.  
2️⃣ 표준점수(z-score)를 이용하여 유의확률을 계산하는 방법이다.  
3️⃣ 데이터의 라벨을 무작위로 섞어 귀무가설 하에서의 분포를 직접 구성하는 비모수적 검정 방법이다.  
4️⃣ 표본의 크기가 충분히 클 때만 사용할 수 있다.
```

```
여기에 정답을 적어주세요!
3️⃣
**순열검정(Permutation Test)**은 데이터의 집단 라벨을 무작위로 섞어 귀무가설이 성립할 때의 검정통계량 분포를 구성하고, 실제 관측값이 그 분포에서 얼마나 극단적인지 평가하는 비모수적 검정 방법이다. 따라서 모집단의 정규분포를 반드시 가정할 필요가 없으며, 표준점수만으로 유의확률을 계산하는 방법도 아니다.
```
