# 1️⃣ 개념 정리 

## 01. API 사용하기

<!-- 새롭게 배운 내용을 자유롭게 정리해주세요.-->API는 프로그램끼리 데이터를 주고받기 위한 규칙이다. 데이터 분석에서는 API를 이용해 웹사이트나 기관에서 필요한 데이터를 받아올 수 있다. 웹 기반 API는 주로 HTTP를 사용하며, 데이터는 JSON, XML 등의 형식으로 전달된다.

## 02.웹 스크래핑 사용하기

<!-- 새롭게 배운 내용을 자유롭게 정리해주세요.-->웹 스크래핑은 웹사이트의 HTML에서 필요한 데이터를 추출하는 기술이다. 파이썬에서는 requests로 웹페이지의 HTML을 가져오고, BeautifulSoup으로 원하는 태그나 텍스트를 찾아 데이터를 추출할 수 있다. 가능하다면 스크래핑보다 먼저 공개 API가 있는지 확인하는 것이 좋다.
